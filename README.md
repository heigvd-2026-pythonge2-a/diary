# Cours Python par la pratique

L'objectif de ce cours est de renforcer les bases de Python et de travailler sur un mini projet en équipe. Le cours est basé sur la pratique et l'apprentissage par l'expérience.

Chaque dossier correspond à une semaine de cours. Son README présente les notions abordées et les fichiers Python permettent de les essayer directement.

- [Semaine 02](02/README.md) : installer Python et comprendre comment un programme est exécuté.
- [Semaine 03](03/README.md) : importer des modules, écrire des fonctions et manipuler des itérables.

Pour suivre les exemples, ouvrez un terminal dans le dossier de la semaine et lancez un fichier avec `python3 nom_du_fichier.py` (ou `python` selon votre installation). Modifiez ensuite une valeur ou une instruction, puis relancez le programme pour observer le résultat.
